## 版本与链接说明

本政策适用于相应地区发行的 YourDrink Android 应用，不限定于某个 App 版本。

政策版本用于标识隐私条款，与 App 版本独立；当前条款标识为 v0.12.1，生效日期为2026年9月3日。本次澄清适用范围并补充译文，没有改变数据处理条款。

不带版本号的链接作为后续固定入口。保留所有既有 `privacy-v0121-*.html` 地址，并同步正文，以兼容旧版 App 和已填写的商店链接；旧网址中的 v0121 不表示仅适用于该 App 版本。

应用内置政策与公开页面需保持一致。应用不需要账号，记录在本机处理和保存，不提供云同步；详细说明以对应地区政策正文为准。
